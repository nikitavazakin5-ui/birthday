САЙТ-ПОЗДРАВЛЕНИЕ ДЛЯ ИРЫ

Как открыть:
1. Распакуй архив в отдельную папку.
2. Открой index.html в браузере.

Музыка (по желанию):
1. Положи аудиофайл MP3 в папку assets.
2. Назови его music.mp3.
3. Нажми кнопку «Включить музыку» на сайте.

Как изменить поздравление:
На сайте нажми «Изменить поздравление» под письмом. Это меняет текст только в открытой вкладке.
Чтобы изменить текст навсегда, отредактируй абзацы внутри блока class="letter-body" в index.html.

Публикация:
Папку можно загрузить в GitHub-репозиторий и включить GitHub Pages в Settings → Pages.
